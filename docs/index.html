Declaración mensual

  • Compara tu cálculo con lo que muestra el SAT
  • Fecha límite según tu RFC
  • Recordatorio opcional el día 17 de cada mes

Instálala gratis

Añadir a Chrome

También puedes instalarla desde el código:

  1. 1
    Descarga el código desde GitHub (Code → Download ZIP) y descomprímelo.
  2. 2
    En esa carpeta, ejecuta npm install && npm run build.
  3. 3
    Abre chrome://extensions y activa el Modo de desarrollador.
  4. 4
    Haz clic en Cargar descomprimida y elige la carpeta dist.
