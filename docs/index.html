Deja de cruzar facturas del SAT con estados de cuenta cada mes

Contabilizate es una extensión de Chrome que convierte tus facturas en un dashboard mes a mes con tus ingresos, gastos, tarjetas de crédito, margen, IVA y retenciones.

🆓 100% gratis 💻 Todo en tu navegador 🔒 Nada se comparte

Instalar gratis Ver el código en GitHub

📊 Qué hace

  • Dashboard mensual. Tus ingresos, gastos y margen real, calculados a partir de tus facturas.
  • Tarjetas de crédito. Ve en qué se te va el dinero mes a mes.
  • Impuestos ya calculados. IVA trasladado y retenciones, sin fórmulas.
  • Facturación en el SAT. Llena los formularios del portal por ti e inicia sesión con tu e.firma.
  • Descarga e importación de CFDI. Baja tus facturas del SAT o arrastra los XML.
  • Montos ocultos por defecto. Ábrela con alguien al lado sin enseñar tus números.

🔒 Tus datos son tuyos

  • Gratis, de verdad. Sin suscripciones, planes premium ni anuncios.
  • Sin servidores. Todo se procesa y se guarda en tu computadora. No hay cuentas ni rastreo.
  • Nada se comparte con nadie. Solo se conecta al portal del SAT cuando tú facturas o descargas.
  • Tu e.firma va cifrada con su propia contraseña.
  • Respaldo opcional en tu propio Google Drive, en una carpeta oculta que solo esta extensión puede leer.
  • Código abierto. Puedes revisar exactamente qué hace en GitHub.

⬇️ Cómo instalarla

Todavía no está en la Chrome Web Store, así que por ahora se instala desde el código:

  1. Descarga el código desde GitHub (botón Code → Download ZIP) y descomprímelo.
  2. En esa carpeta, ejecuta npm install && npm run build.
  3. Abre chrome://extensions y activa el Modo de desarrollador.
  4. Haz clic en Cargar descomprimida y elige la carpeta dist.
